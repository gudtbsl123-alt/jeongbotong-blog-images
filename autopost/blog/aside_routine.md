# 네이버 블로그 임시저장 — Aside 루틴

클로드 코드가 `autopost/blog_queue/` 에 원고를 넣어 두면, Aside가 매일 한 번 원고 1개를
**오카와리 블로그(blog.naver.com/jeongbotong_japan)에 임시저장까지만** 해 둡니다.
발행은 사진·한 줄을 손으로 더한 뒤 직접 누릅니다.

---

## 1. 처음 한 번 준비 (10분)

1. **Aside 설치·로그인** — aside.com 에서 내려받아 설치합니다(Windows·Mac 모두 지원).
2. **네이버 로그인** — Aside 브라우저에서 블로그 계정으로 로그인해 둡니다.
   비밀번호를 Aside Vault에 저장해 두면, 로그인이 풀려도 AI에게 비밀번호를 보여 주지 않고 자동 입력합니다.
3. **폴더 권한** — `Settings > Agents > File permissions` 에서 내 컴퓨터의 대기열 폴더를 **Can edit** 으로 추가합니다.
   - 예) `C:\Users\(이름)\Documents\GitHub\jeongbotong-blog-images\autopost\blog_queue`
   - Aside가 원고를 읽고, 끝나면 그 폴더에 `drafted.txt` 를 남겨야 해서 편집 권한이 필요합니다.
4. **루틴 만들기** — `Settings > Routines > Create a routine`
   - 종류: **Cron routine** (정해진 시각마다 새 작업 시작)
   - 시각: 컴퓨터가 켜져 있는 시간, 하루 1번 (예: 매일 21:10)
   - 권한: **Guard** (승인한 폴더 안에서만 작업)
   - 지시문: 아래 2번 상자 전체를 복사해 붙여 넣고, `{대기열 폴더}` 를 3번에서 넣은 폴더 경로로 바꿉니다.
5. **첫 주는 지켜보기** — 루틴을 만든 뒤 한 번은 직접 실행해 화면을 지켜보세요.
   사진 버튼 위치처럼 막히는 곳이 있으면 지시문에 한 줄 보태면 됩니다.

> 루틴은 컴퓨터가 켜져 있고 Aside가 실행 중일 때만 돕니다. 무료 플랜은 루틴 3개까지입니다.

---

## 2. 루틴 지시문 (그대로 복사)

```
[오카와리 블로그 임시저장]

목표: 내 컴퓨터의 대기열 폴더에서 아직 처리 안 된 블로그 원고 1개를 골라
네이버 블로그 글쓰기 화면에 넣고 '임시저장'까지만 한다.

절대 규칙
1. '발행' 버튼은 어떤 경우에도 누르지 않는다. 발행 설정 창도 열지 않는다.
2. 임시저장 목록이나 이미 있는 글을 지우거나 고치지 않는다.
3. 한 번 실행에 원고 1개만 처리한다.
4. 원고 문장을 고치거나 덧붙이거나 다듬지 않는다. 적힌 그대로 넣는다.
   [✍️ ...] 로 된 줄도 그대로 넣는다 (내가 발행 전에 직접 채울 자리).
5. 로그인 창, 캡차, 본인 인증, 처음 보는 경고창이 나오면 그 자리에서 멈추고 보고한다.

1단계 — 원고 고르기
- 대기열 폴더: {대기열 폴더}
- 하위 폴더 중 이름이 _ 로 시작하지 않고, 안에 drafted.txt 와 error.txt 가 없는 폴더를
  이름순으로 정렬해 첫 번째 하나를 고른다. 없으면 "처리할 원고 없음"이라고 보고하고 끝낸다.
- 그 폴더의 blog.md 를 읽는다. '---' 줄 위는 머리말(제목·카테고리·태그), 아래는 본문이다.

2단계 — 글쓰기 화면 열기
- https://blog.naver.com/jeongbotong_japan/postwrite 를 연다.
  안 열리면 https://blog.naver.com/jeongbotong_japan 에서 '글쓰기' 버튼을 누른다.
- "작성 중인 글이 있습니다" 같은 이어쓰기 창이 뜨면 '취소'를 눌러 새 글로 시작한다.
- 도움말·안내 패널이 뜨면 닫는다.

3단계 — 내용 넣기
- 제목 칸에 머리말의 '제목:' 뒤 내용을 넣는다.
- 본문을 위에서부터 순서대로 넣는다.
  · 보통 줄: 본문 글자로 입력한다. 빈 줄은 문단을 나눈다.
  · '## ' 로 시작하는 줄: 글자 스타일을 '소제목'으로 바꿔 '## ' 를 뺀 내용을 입력하고,
    다음 줄부터 다시 '본문' 스타일로 돌아온다.
  · '[사진 파일이름]' 줄: 그 자리에서 위쪽 도구 막대의 '사진' 버튼을 눌러
    같은 폴더의 그 파일을 올린다. 사진이 올라간 뒤 다음 줄로 넘어간다.
  · '[장소 가게이름]' 줄: 도구 막대 '장소' 버튼으로 가게 이름을 검색해,
    결과의 이름이 원고와 맞을 때만 추가한다. 맞는 결과가 없으면 건너뛰고 보고에 적는다.
  · '[✍️ ...]' 줄: 그대로 입력한다.
- 편집기가 권하는 맞춤법 교정, AI 글쓰기, 자동 이모티콘 같은 기능은 쓰지 않는다.
- 머리말의 카테고리·태그는 입력하지 않는다 (발행할 때 내가 직접 넣는다).

4단계 — 임시저장
- 오른쪽 위 '저장' 버튼(임시저장)만 누른다. '발행'은 누르지 않는다.
- 저장 버튼 옆 숫자가 늘거나 저장 완료 표시가 나오면 성공이다.
- 저장 버튼 옆 숫자를 눌러 임시저장 목록 맨 위에 방금 제목이 있는지 눈으로만 확인하고 닫는다.

5단계 — 기록과 보고
- 성공: 그 원고 폴더에 drafted.txt 를 만들고 다음을 적는다.
  "임시저장 완료 YYYY-MM-DD HH:MM / 사진 N장 / 장소 N개 / 건너뛴 것: (없으면 없음)"
- 실패: 그 폴더에 error.txt 를 만들어 어느 단계에서 왜 멈췄는지 적고, 글쓰기 화면은 그대로 둔다.
- 마지막에 한 줄로 보고한다: 처리한 폴더 이름, 결과, 건너뛴 것.
```

---

## 3. 다음 날 할 일 (발행은 직접)

1. 네이버 블로그 앱이나 PC에서 글쓰기 → **임시저장 목록**에서 그 글을 엽니다.
2. `[✍️ ...]` 자리를 내 말로 채우고, 직접 찍은 사진이 있으면 한두 장 더 넣습니다.
3. 카테고리·태그(원고 머리말 참고)를 넣고 **발행**.

## 4. 막혔을 때

| 증상 | 할 일 |
|---|---|
| 폴더에 `error.txt` 가 생김 | 내용을 읽고 원인을 고친 뒤 `error.txt` 를 지우면 다음 실행 때 다시 합니다. |
| 같은 원고가 두 번 저장됨 | 1단계 지시대로 `drafted.txt` 를 만들었는지 확인. 폴더 편집 권한(Can edit)이 빠졌을 가능성이 큽니다. |
| 로그인 창에서 멈춤 | Aside에서 네이버에 다시 로그인하고 Vault에 저장해 두세요. |
| 사진이 안 올라감 | 파일 이름이 원고의 `[사진 ...]` 과 똑같은지(확장자 포함) 확인하세요. |
